# 🔗 Linktree Pessoal

Página pessoal desenvolvida para reunir, em um único lugar, meus projetos, redes sociais e informações profissionais.

## 💡 Sobre o projeto

O projeto funciona como um **Linktree pessoal**, apresentando uma página simples e responsiva com minha foto, nome, formação acadêmica e links para projetos e redes sociais.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Boxicons

## 📌 Conteúdo

A página disponibiliza links para:

* 🧮 Projeto Calculadora
* 🐱 Projeto Pokemon
* 🎙️ Projeto JuliaVoices
* 💼 LinkedIn
* 🐙 GitHub
* 📷 Instagram

## 🎯 Objetivo

Praticar o desenvolvimento web utilizando HTML, CSS e JavaScript e criar uma página centralizadora para facilitar o acesso aos meus projetos e perfis online.
